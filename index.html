ⓘ How to use this tool

1. Enter the size of each group into the input field below (for example, 8,5,10 means group 1 has 8 people, group 2 has 5 people, etc.)

2. Enter the number of tables available (each table is 10 seats)

3. Adjust optimization settings if needed

4. Click "Run Algorithm" and wait for the results to appear below

5. Review the seating plan and make any necessary adjustments
